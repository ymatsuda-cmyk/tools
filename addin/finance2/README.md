# finance2 — 試算表取込とBS・PLダッシュボード

合計残高試算表（月次）のPDFをブックの台帳に登録し、BS・PLを可視化するExcelアドインです。PDFの読み取りはpdf.jsのテキストレイヤーを使い、AIは使いません。

## タブ

| タブ | 内容 |
|---|---|
| 取込 | PDFを複数ドロップ → 台帳と照合（未登録／差分あり／同じ／読み取り失敗）→ 反映。年度×12か月の登録状況、取込履歴 |
| 全体 | （金額はすべて円のフル桁）売上高・営業利益の累計、現預金、自己資本比率。月次売上の前期比較、BS構成、前年から大きく動いた科目 |
| 月別 | 月を選んでPL（当月／累計 × 前年同月）とBS（当月末 × 前月末）。行を押すと科目タブへ |
| 科目 | 1科目の月次推移を最大3期重ねて表示、月別の前年差 |
| 予測 | 前年同月比／移動平均／傾向線で残り月（当期が揃っていれば翌期）を予測。約80%の幅つき |
| 計画 | 計画シートの作成（前期の月次実績ベース）と、計画と実績の比較（売上高・営業利益のKPI、月次／累計グラフ、科目別の計画累計・実績累計・差額） |
| 予実 | ①売上（累計の積み上げと見込み）、②コスト（原価・販管費の月別と突発）、③利益率（年度末の着地と調整後営業利益率）。下記「予実タブ」 |

全体・科目タブのグラフには **前期と比較／異常値／予測／計画** の切り替え（ON/OFF）があります。

- 前期と比較：前期・前々期の同じ月を点線で重ねる（前期の月次データがあるとき）
- 異常値：ふだんの振れ幅から大きく外れた月、前年同月から±50%以上動いた月を丸で囲み、一覧にする。PLは当月発生額、BSは前月からの増減で判定。連続する月は1件にまとめる
- 予測：期の途中なら残り月の予測を点線と幅で重ね、KPIに着地見込を出す（方法は予測タブで選んだもの）
- 計画：計画シートの月次計画を線で重ね、KPIに計画比を出す

## 表示データの読み方

月次PL・月次BSシートがあるブックでは、ダッシュボードはシートの値を読みます（取込していない月も表示）。シートにない月（前期以前など）は TB_明細 を科目対応で集計して補います。取込の照合（差分・前月とのつながり）は TB_明細 で行います。

## 予実タブ

計画シートの売上高・売上原価・販管費と、月次PLの実績を比べます。実績のない月は「見込みの前提」で計算します。

- 実績の確定月：月次PL／月次BSの4行目（月の列）に何か入っている（●など）いちばん右の月までを実績、それ以降を見込みとする。両方のシートにあれば遅い方。印は文字（●など）で、4行目が月の見出し行のシートでは使わない。印がなければ、データのある最新月までを実績とする

- 見込みの前提（スライダー）：受注残（受注済・未計上）、開発（既存）追加見込み／月、開発（新規）見込み／月、今後の原価率、販管費（計画比）。ブックの設定に保存され、次回も同じ値で開く。「既定に戻す」で計画どおりの値に戻る
- ①売上：累計の積み上げ。実績＝面、見込み＝破線、計画＝点線。保守／開発（既存）／開発（新規）のボタンをONにした区分だけ色分けし、下から 保守→開発（既存）→開発（新規） の順に積む（OFFの区分は抜いて詰め、上に「その他」としてまとめる）。区分別の詳細（実績累計・同月計画・計画比・年度末見込み・達成に必要な月額）はアコーディオン
- ②コスト：原価・販管費の月別棒グラフ。計画を横線で重ね、見込み月は点線の枠。突発＝実績月で「その月までの累計実績が計画の累計の○%超」（既定 120%、原価と販管費で別に設定、条件はアコーディオン。計画の累計が0円なら実績があれば突発）
- ③利益率：年度末の着地を「計画」「受注確定ベース（実績＋保守＋受注残）」「着地見込み（＋営業見込み）」の3本で比べる。売上とコスト（原価＋販管費）を並べ、見込み部分は斜線。調整後営業利益率（税抜）＝（営業利益−消費税の納付見込み）÷（売上÷1.1）。消費税の納付見込み＝売上×10/110×（1−みなし仕入率）。目標（既定15%）とみなし仕入率（既定50%）はアコーディオンで変更。目標に届かないときは必要な追加受注額、今後の案件で許容できる原価率の上限を表示

### 売上高の内訳（保守・開発(既存)・開発(新規)）

①の色分けは、計画シートと月次PLの売上高の下にある「保守」「開発(既存)」「開発(新規)」の行から読みます（行名の全角・半角括弧と空白は区別しない）。

- 内訳の行は手入力。取込でPDFの値を書き込まず、科目対応にも載せない。全体・月別・科目などのタブでは科目として扱わない
- 月次PLに内訳がない月は、売上高をすべて開発（既存）として表示する。内訳の合計が売上高と合わない月は、差を開発（既存）に含めて表示し、警告を出す
- 見込み月の保守は計画シートの保守を使う
- 計画シートを作り直すときは、内訳の行も前期の月次PLの値を基準に同じ式（調整率・調整額）で作る

## 計画シート

計画タブの「計画シートを作成」で「計画」シートを作ります。行は月次PLと同じ並びです。

- 上段：計画。各月 ＝ ROUND(前期同月 ×(1＋調整率) ＋ 調整額÷12, 0)。C列＝調整率、D列＝年間の調整額（黄色のセル）。月のセルを直接書き換えてもよい
- 合計・利益の行は月次PLの数式を同じ位置関係で写す
- 下段：前期の月次実績（計画の基準、編集しない）
- finance2は計画シートの値を読むので、Excelで直したあと再読み込みボタンで反映される

## ブックのシート

| シート | 内容 |
|---|---|
| 月次PL／月次BS | 名前の前方一致で探す（例：月次PL(実績入力)）。見出し行の `2025/10` 形式の列に、PLは当月発生額、BSは月末残高を書き込む。数式のセル（合計・利益行）には書き込まない。なければ新規作成 |
| 科目対応 | 月次シートの行 ⇔ PDFの科目の対応表。初回に自動作成し、手で直すと次回から優先。複数科目は「＋」でつなぐ |
| TB_明細 | 取り込んだ全期間の試算表（1行＝1か月×1科目）。ダッシュボード・差分確認の元データ |
| 取込履歴 | 取込ID, 期間, ファイル名, 会社名, 行数, 取込日時, 版, 状態, 理由, 月次シート検算 |
| TB_退避 | 差し替え前の行 |
| 科目マスタ／設定 | 行種別（明細／集計）、期首月（既定10）・会社名・金額区分・異常値の下限額（既定50,000円。行がなければ既定値） |
| 計画 | 計画タブから作成（下記） |

### 月次シートへの書き込み

- 行の取込元は「科目対応」→ 既定の対応 → 科目名の一致 の順で決める。照合時は `（旧:〜）` の注記と空白、括弧書きを無視する。
- 既定の対応：有形・無形固定資産＝有形固定資産計＋無形固定資産計、保証金（投資その他）＝投資その他の資産計、その他・固定負債＝買掛金＋未払金＋固定負債計、販管費 合計＝販売費及び一般管理費、営業外収益（受取利息等）＝営業外収益。ただし自分の行がある科目は合算から外す（月次BSに未払金の行があれば、その他・固定負債＝固定負債計のみ）。
- 行を追加したとき、月以外の列（累計実績・累計計画・差額など）の数式は上の行からコピーする（他シート参照の数式は除く）。
- どの行にも対応しない科目（金額または動きがあるもの）は行を追加する。位置は同じ区分の次の科目の直前。区分の先頭には入れず2行目の直前にする（`SUM(先頭:末尾)` の範囲から外れないように）。追加した行は薄い橙で塗る。
- 差し替えたときも同じ列を上書きするだけなので、二重計上にならない。
- 月の列がない（翌期など）場合は台帳だけ更新してエラーを表示。列を足してから取込タブの「月次シートへ反映し直す」を実行する。

### 取込時の検算

書き込み後に次の行の値（数式の再計算後）をPDFの集計値と比べ、取込タブと取込履歴に結果を出す。

- 月次PL：売上総利益、販管費合計、営業利益、経常利益
- 月次BS：現金預金 計、流動資産 計、固定資産 計、資産 合計、負債 合計、純資産 合計、負債・純資産 合計

差額が出たときは、科目対応の取込元か、合計行の数式の範囲を確認する。

## 二重計上しない仕組み

- キーは「区分:科目コード」。コードのない科目（資本金・繰越利益剰余金など）は「区分:#科目名」。
- 差し替えは月単位。対象月の行を TB_退避 に移して削除してから、PDFの行を追記する。
- 一部の科目だけの採用はできない（貸借が崩れるため）。

## 読み取りと検算

- 期間は表題の「自 YYYY年M月D日 至 …」から取得（和暦も可）。1か月でない場合はエラー。
- 各行で「繰越残高 ± 借方 ∓ 貸方 = 残高」を検算。資産合計と負債・純資産合計の一致を確認。
- 前月・翌月が登録済みなら、残高と繰越残高のつながりを確認して警告を出す。
- 期首月なのにPLの繰越残高が0でなければ警告。
- PLの当月発生額は「残高 − 繰越残高」（集計行の借方・貸方は差し引き後の額のため）。

## ブックを開いたときの自動表示

台帳シート（TB_明細）があるブックでは、アドインを一度開いた時点でブックに自動表示の設定を保存します。次回からそのブックを開くとタスクペインが自動で開きます。台帳のない普通のブックでは自動表示しません。ブックごとのON/OFFはメニューの「このブックを開いたら自動で表示：切り替え」で変えられます（OFFにしたブックは自動でONに戻しません）。Excelのスタート画面（ブックを開く前）では表示されません。

## 配置

`tools/addin/finance2/` に置き、`manifest.xml` をアップロードします。pdf.js（3.11.174）は取込時にcdnjsから読み込みます。

共通メニューに載せる場合は `common/menu.json` の「ツール」に次を追加します。

```json
{ "id": "finance2", "label": "財務（試算表）", "icon": "", "url": "https://ymatsuda-cmyk.github.io/tools/addin/finance2/" }
```
