# ステップ数集計アドイン

フォルダに取引先名を割り当て、ダッシュボードで全体像を把握しつつ、取引先・拡張子のピルで絞り込んだファイル一覧を確認できる Excel 作業ウィンドウアドインです。集計はすべてアドイン側のメモリで行い、シートには「割当」「除外」「出力結果」だけを置きます。

## ファイル構成

```
step-count-addin/
  manifest.xml        アドインのマニフェスト
  package.json        ローカル配信用のスクリプト
  src/
    taskpane.html     作業ウィンドウのマークアップ
    taskpane.css      スタイル
    taskpane.js       読み込み・割当解決・集計・出力
```

## ブックの準備

シート名は `taskpane.js` 冒頭の `SHEET` で変えられます。

### `データ`（必須・1行目はヘッダー）

| A: パス | B: 拡張子 | C: 総ステップ | D: 実ステップ |
|---|---|---|---|
| `10.1.1.3\winntdir\delphi5\Amp\PROC.pas` | pas | 3989 | 2766 |

- 区切りは `\` でも `/` でも構いません。先頭の `\\` は自動で落とします。
- B列が空の場合はファイル名の拡張子を使います。
- C・D列は数値でも `1,234` のような文字列でも読めます。
- 表示・集計にはすべて **実ステップ（D列）** を使います。総ステップは現在のUIには出てきません。

### `割当`・`除外`（無ければ初回起動時に自動作成）

| A: フォルダパス | B: 取引先名 / メモ |
|---|---|
| `10.1.1.3\winntdir\delphi5\Amp` | ライターム商事 |
| `10.1.1.3\winntdir\delphi5\Amp\旧バージョン` | 旧版・バックアップ |

いずれも**最長一致した祖先が勝つ**方式です。

## 起動手順

```
cd step-count-addin
npm run cert
npm start
```

サイドロード後、リボンの「ステップ数集計」から作業ウィンドウを開きます。タブは次の3つです。

## タブ構成

### ダッシュボード（既定で表示）

フィルタなしの全体サマリーです。

- **合計ステップ／ファイル数／取引先数** の3カード。**合計ステップとファイル数はいずれも（未割当）を除いた数字**です（カードに「未割当を除く」と注記）。
- **取引先別**：ステップ数の多い順に横棒で表示。各行は「ファイル数件 / ステップ数」。**（未割当）は一覧に出しません**（取引先が割り当てられているものだけを対象にしています）。
- **拡張子別（全体・未割当を除く）**：（未割当）配下のファイルを除いた、拡張子ごとのステップ数の全体像です。

除外フラグの付いたフォルダ（`旧バージョン`など）は、ダッシュボードでは常に集計から除きます。

### ソース一覧（旧「集計」タブ）

取引先 › 拡張子の2段ピルで絞り込みながら、該当ファイルを一覧できます。**（未割当）のファイルは対象外です**（未割当は件数が大きくなりがちで、一覧の反応が遅くなる主因だったため常に除外しています。未割当の総量はダッシュボードの「合計ステップ」「ファイル数」と「取引先別」の合計との差分から把握できます）。

- 取引先ピルを選ぶと、拡張子ピルの選択肢がその時点の絞り込みに応じて絞られます。取引先を変えると拡張子は「すべて」に戻ります。
- フォルダ単位の絞り込みは行いません。割当フォルダ別に見たい場合は割当タブの「取引先で絞り込み」を使うか、「シートに出力」した `集計_クロス` を参照してください。
- 「除外行を外す」を切れば、除外フラグの付いたファイルも一覧・件数に含まれます。
- 一覧には フォルダ／ファイル名／拡張子／ステップ数 を表示し、ステップ数の降順で並びます。
- 「シートに出力」は、現在のピル選択に関わらず**全件**を対象に、「除外行を外す」の設定だけを反映して `集計_取引先` `集計_拡張子` `集計_クロス` の3シートを作り直します。`集計_クロス` は取引先・フォルダ・拡張子の平坦形式なので、そのままピボットテーブルの元データに使えます。

### 割当

「取引先で絞り込み」のピルで、ツリーを特定の取引先（または「未割当のみ」）に関係するフォルダだけに絞り込めます。ピルはステップ数の多い取引先順に並びます。絞り込み中は、対象フォルダへ辿り着くための親フォルダも（対象外でも）表示され、自動的に展開されます。「すべて」に戻すと通常のツリー表示に戻ります。

フォルダツリーが総ステップ数の降順で並びます。チェックボックスは常に操作でき、チェックすると配下のフォルダも自動でチェックされます。ボタンは2つだけです。

- **割り当て** — 取引先名を入力してから押します。**チェックしたフォルダそれぞれに**、その取引先を個別に割り当てます（配下は継承でも自動的に含まれますが、チェックしたフォルダは親・子の関係に関わらずすべて自分自身の割当として書き込まれます）。取引先名が空欄だと押せません。
- **除外** — 取引先名の入力は不要です。チェックしたフォルダの割当・継承をそのフォルダだけ外します。個別に割り当てたフォルダを選べば割当そのものを削除し、「継承 ○○」と表示されているフォルダを選べば、そのフォルダだけ継承を断ち切る `（解除）` という印を`割当`シートに書き込みます（画面上は通常の未割当フォルダと同じ見た目になります）。割当も継承もないフォルダを選んだ場合は何も変わらず、その旨を知らせます。

`旧バージョン`のような重複フォルダを取引先の集計から外したい場合は、そのフォルダだけチェックして「除外」を押してください。未割当になったフォルダはダッシュボード・ソース一覧のどちらにも出てこないので、実質的にその取引先の集計から除かれます。あとで元の取引先に戻したい場合は、そのフォルダをチェックして取引先名を入力し、「割り当て」を押し直してください（`（解除）`の印は上書きされます）。

割り当て・除外を押すと `割当` シートに保存され、画面上は対象フォルダのバッジが変わるだけです。データシートの読み直しは行わないので、7万行規模でも待たされません（スクロール位置も保たれます）。Excel 側で `データ` シートや `割当` シートを直接編集した場合だけ、ステータス行の ↻ ボタンで読み直してください。

**注意**：チェックは親を選ぶと配下も自動で全部チェックされ、「割り当て」は**チェックが入っているフォルダすべてに**個別のエントリを書き込みます。大きなフォルダを丸ごとチェックしたまま押すと、`割当`シートの行数もその分増えます。特定の配下だけ含めたくない場合は、そのフォルダのチェックを外してから押してください（外したフォルダには何も書き込まれず、チェックしたフォルダの継承に従います）。

## 実装メモ

- 読み込みは `getUsedRange()` の行数を測ってから `CHUNK`（既定2000行）ずつ読み、以降はすべて JS 側で処理します。行ごとに `context.sync()` を呼ぶ実装は数千行で分単位になるため避けています。
- 割当の解決は `lookup()` でフォルダ階層を末尾から遡り、最初に一致した祖先を採用します。
- 継承の切断は `UNASSIGN_MARK`（`（解除）`という文字列）を `割当` シートにそのフォルダのキーとして書き込むことで実現しています。`markTree()` と `buildModel()` の両方でこの印を「取引先なし」として扱い、祖先からの継承をそこで打ち切ります。この印が付いたフォルダは通常の未割当フォルダと同じ表示にしており、専用バッジは出しません。
- 「割り当て」「除外」はどちらも `applyAssign(mode)` の `"assign"` / `"remove"` を呼ぶだけのシンプルな2択です（`bindUi()` 内）。「割り当て」はチェックされている全パスにそのまま書き込みます（`topmostPicks()` による最上位への集約はしません）。「除外」は今まで通り `topmostPicks()` で最上位のフォルダに絞ってから、個別割当の削除または継承の切断を行います。
- 割当を変えたあと、Excel からの再読み込みは行いません。`割当` シートに書き込んだあと `refreshAssignments(changed)` がメモリ上のモデルだけを更新します。変更されたパスの配下にある行だけを対象に `lookup()` で再解決し、`markTree()` でツリーのバッジを付け直して再描画します。7万行規模でも体感で終わります（以前は毎回 `reload()` を呼んでデータシート全体を読み直していたため、割り当てのたびに数十回の Excel 往復が発生していました）。データシート全体の読み直しは、起動時とステータス行の ↻ ボタンを押したときだけです。
- ツリーの再描画では `host.scrollTop` を退避・復元しているので、割り当て後もスクロール位置が保たれます。展開されていないノードは描画しないため、DOM のノード数は開いている範囲だけに収まります。
- 取引先の絞り込みピルは `renderAssignPills()` に分離してあり、展開・折りたたみやチェック操作では作り直しません（割当が変わったときと起動時のみ）。
- 「割当フォルダ」は `groupOf()` が `f.folder[f.assignDepth - 1]`（割当・解除が実際に行われたフォルダの名前）を返すことで実現しています。
- 割当タブの「取引先で絞り込み」は `assignKeepSet()` がツリー全体を1回走査し、条件に一致するノードとその祖先パスだけを集めます。一致しないノードは描画時に丸ごとスキップ（子孫も辿らない）します。ピルの並び順は `aggregateAll(false).vendors`（ステップ数降順、未割当を除く）をそのまま使います。
- ダッシュボードは `aggregateAll()`、ソース一覧は `vendorOptions()` / `folderOptions()` / `extOptions()` / `filteredSourceRows()` が担当します。ピルは実 DOM の `<button>` なので、キーボード操作（Tab / Enter / Space）も追加コードなしで機能します。
- 出力用の集計は `aggregateFull()` が担い、ソース一覧の「除外行を外す」設定だけを反映して全件を対象にします（ピルの絞り込みは出力に影響しません）。`除外`シート・`excludeMap`（`f.excluded`、旧版・バックアップの個別フラグ）自体は読み込み専用として残っており、シートに直接エントリを書けば引き続き効きますが、割当タブのボタンからは操作しません。
- 出力シートは毎回使用範囲をクリアして書き直します。ここに手で列を足しても消えるので、加工は別シートで行ってください。

## 拡張しやすい箇所

- ダッシュボードの取引先別・拡張子別バーをクリックしてソース一覧に絞り込み状態で遷移させたい場合は、`statRow()` にクリックハンドラを足し、`switchTab("source")` の前に `state.srcVendor` 等をセットします。
- 取引先ピルが多くなり折り返しが窮屈な場合は、`pillRow()` の出力元に検索用テキスト入力を足し、`vendorOptions()` の結果をその場でフィルタします。
- コメント率（総 − 実）を出したい場合は、`データ`シートのC列（総ステップ）を各集計関数に足し込みます。
