# ステップ数集計アドイン

フォルダに取引先名を割り当て、ダッシュボードで全体像を把握しつつ、取引先・割当フォルダ・拡張子のピルで絞り込んだファイル一覧を確認できる Excel 作業ウィンドウアドインです。集計はすべてアドイン側のメモリで行い、シートには「割当」「除外」「出力結果」だけを置きます。

## ファイル構成

```
step-count-addin/
  manifest.xml        アドインのマニフェスト
  package.json        ローカル配信用のスクリプト
  src/
    taskpane.html     作業ウィンドウのマークアップ
    taskpane.css      スタイル
    taskpane.js       読み込み・割当解決・集計・出力
```

## ブックの準備

シート名は `taskpane.js` 冒頭の `SHEET` で変えられます。

### `データ`（必須・1行目はヘッダー）

| A: パス | B: 拡張子 | C: 総ステップ | D: 実ステップ |
|---|---|---|---|
| `10.1.1.3\winntdir\delphi5\Amp\PROC.pas` | pas | 3989 | 2766 |

- 区切りは `\` でも `/` でも構いません。先頭の `\\` は自動で落とします。
- B列が空の場合はファイル名の拡張子を使います。
- C・D列は数値でも `1,234` のような文字列でも読めます。
- 表示・集計にはすべて **実ステップ（D列）** を使います。総ステップは現在のUIには出てきません。

### `割当`・`除外`（無ければ初回起動時に自動作成）

| A: フォルダパス | B: 取引先名 / メモ |
|---|---|
| `10.1.1.3\winntdir\delphi5\Amp` | ライターム商事 |
| `10.1.1.3\winntdir\delphi5\Amp\旧バージョン` | 旧版・バックアップ |

いずれも**最長一致した祖先が勝つ**方式です。

## 起動手順

```
cd step-count-addin
npm run cert
npm start
```

サイドロード後、リボンの「ステップ数集計」から作業ウィンドウを開きます。タブは次の3つです。

## タブ構成

### ダッシュボード（既定で表示）

フィルタなしの全体サマリーです。

- **合計ステップ／ファイル数／取引先数** の3カード。**合計ステップは（未割当）を除いた金額**です（カードに「未割当を除く」と注記）。ファイル数は全ファイル数（未割当を含む）。
- **取引先別**：ステップ数の多い順に横棒で表示。各行は「ファイル数件 / ステップ数」。（未割当）は最下段にオレンジ色で表示します。
- **拡張子別（全体・未割当を除く）**：（未割当）配下のファイルを除いた、拡張子ごとのステップ数の全体像です。

除外フラグの付いたフォルダ（`旧バージョン`など）は、ダッシュボードでは常に集計から除きます。

### ソース一覧（旧「集計」タブ）

取引先 › 割当フォルダ › 拡張子の3段ピルで絞り込みながら、該当ファイルを一覧できます。

- ピルを選ぶと、その下の段（割当フォルダ、拡張子）の選択肢がその時点の絞り込みに応じて絞られます。取引先を変えると下2段は「すべて」に戻ります。
- 「割当フォルダ」は、割当（または解除）が実際に行われたフォルダ自身の名前です。例えば `TouchPanel` に割り当てていれば、その配下の孫フォルダにあるファイルも「割当フォルダ」は `TouchPanel` としてまとまります。
- 「除外行を外す」を切れば、除外フラグの付いたファイルも一覧・件数に含まれます。
- 一覧には フォルダ／ファイル名／拡張子／ステップ数 を表示し、ステップ数の降順で並びます。
- 「シートに出力」は、現在のピル選択に関わらず**全件**を対象に、「除外行を外す」の設定だけを反映して `集計_取引先` `集計_拡張子` `集計_クロス` の3シートを作り直します。`集計_クロス` は取引先・フォルダ・拡張子の平坦形式なので、そのままピボットテーブルの元データに使えます。

### 割当

フォルダツリーが総ステップ数の降順で並びます。チェックボックスは常に操作でき、チェックすると配下のフォルダも自動でチェックされます。取引先名を入力して「割り当て」を押すと、チェックした中でいちばん上位のフォルダにだけ割当が書き込まれます。

割当済み・継承済みのフォルダも選択できます。「解除」の動作はフォルダの状態によって変わります。

- 個別に割り当てたフォルダを選んだ場合 → その割当を削除します。
- 「継承 ○○」と表示されているフォルダを選んだ場合 → そのフォルダだけ継承を断ち切り、`（解除）`という印を`割当`シートに書き込みます。ツリーには「解除済み」バッジが付きます。もう一度同じフォルダで「解除」を押すと印が消え、継承が復元されます。
- 割当も継承もないフォルダを選んだ場合 → 何も変わらず、その旨を知らせます。

「除外」ボタンは同じ選択に対して除外フラグを立てます。`旧バージョン` `back1205` `v101` `old` `SAVE` `backup` あたりを潰していく想定です。

## 実装メモ

- 読み込みは `getUsedRange()` の行数を測ってから `CHUNK`（既定2000行）ずつ読み、以降はすべて JS 側で処理します。行ごとに `context.sync()` を呼ぶ実装は数千行で分単位になるため避けています。
- 割当・除外の解決は `lookup()` でフォルダ階層を末尾から遡り、最初に一致した祖先を採用します。
- 継承の解除は `UNASSIGN_MARK`（`（解除）`という文字列）を `割当` シートにそのフォルダのキーとして書き込むことで実現しています。`markTree()` と `buildModel()` の両方でこの印を「取引先なし」として扱い、祖先からの継承をそこで打ち切ります。
- 「割当フォルダ」は `groupOf()` が `f.folder[f.assignDepth - 1]`（割当・解除が実際に行われたフォルダの名前）を返すことで実現しています。
- ダッシュボードは `aggregateAll()`、ソース一覧は `vendorOptions()` / `folderOptions()` / `extOptions()` / `filteredSourceRows()` が担当します。ピルは実 DOM の `<button>` なので、キーボード操作（Tab / Enter / Space）も追加コードなしで機能します。
- 出力用の集計は `aggregateFull()` が担い、ソース一覧の「除外行を外す」設定だけを反映して全件を対象にします（ピルの絞り込みは出力に影響しません）。
- 出力シートは毎回使用範囲をクリアして書き直します。ここに手で列を足しても消えるので、加工は別シートで行ってください。

## 拡張しやすい箇所

- ダッシュボードの取引先別・拡張子別バーをクリックしてソース一覧に絞り込み状態で遷移させたい場合は、`statRow()` にクリックハンドラを足し、`switchTab("source")` の前に `state.srcVendor` 等をセットします。
- 取引先ピルが多くなり折り返しが窮屈な場合は、`pillRow()` の出力元に検索用テキスト入力を足し、`vendorOptions()` の結果をその場でフィルタします。
- コメント率（総 − 実）を出したい場合は、`データ`シートのC列（総ステップ）を各集計関数に足し込みます。
