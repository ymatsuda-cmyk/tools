# LedgerPilot — 仕訳台帳アドイン

弥生会計の「仕訳日記帳」CSVを月別シートに台帳化し、損益ダッシュボードで確認する Excel アドインです。

- 公開先: `https://ymatsuda-cmyk.github.io/tools/addin/ledgerpilot/`
- バージョン: `rev_20260930_lp002`（画面右下に表示）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `ledger-core.js` | CSV解析・伝票キー・差分・差し替え計画・損益集計（取込ツール／アドイン共用） |
| `ledger-diffview.js` | 差分プレビュー画面（共用） |
| `ledgerpilot.css` | 共通スタイル（`lp-` 接頭辞） |
| `import.html` / `import.js` | ① 単体の取込ツール（ブラウザでxlsxを読み書き） |
| `index.html` / `app.js` / `app.css` / `charts.js` | ② アドイン（全体・月別・科目・取込） |
| `manifest.xml` / `commands.html` / `icons/` | アドイン登録用 |

## 台帳ブックの構成

| シート | 内容 |
|---|---|
| `仕訳_YYYY-MM` | その月の仕訳。A〜D列は管理列（伝票キー・行キー・内容ハッシュ・取込日時、非表示）、E列以降はCSVの57列そのまま |
| `科目マスタ` | 科目コード・科目名・区分。**区分はExcelで直接編集でき、ダッシュボードに反映**（↻で再読込） |
| `取込履歴` | 取込日時・CSV名・指定期間・年月・追加/変更/削除/同一の件数 |

区分の初期値はコード帯で決めています（500番台=売上高、600番台=売上原価、700番台=販管費、800〜849=営業外収益 など）。

## 差し替えのルール（2重計上しない仕組み）

1. CSVを選ぶと日付範囲から **指定期間**（月初〜月末）を自動設定。月の途中までのCSVなら終了日を合わせる。
2. 指定期間内の台帳の仕訳を、CSVの内容で **丸ごと置き換える**。期間外はそのまま残す。
   → 同じCSVを何度取り込んでも、期間の重なるCSVを取り込んでも件数は増えない。
3. 置き換える前に、月ごと・伝票ごとの差分（追加／変更／削除／同一）を表示。変更は列単位で旧→新を表示。
4. 差し替える月はチェックで選べる。日付が月をまたいで変わった伝票がある月同士は **連動して一緒に選択**される。
5. 反映直前に全月横断で行キーの重複を検査し、重複があれば中止。

伝票キーは「新規登録日付＋新規登録者」（CSVの伝票No.が空のため）。弥生側で伝票を削除して入力し直した場合は、差分上「削除＋追加」と表示されますが、期間置き換えなので2重にはなりません。

## 毎月の運用

1. 弥生会計で仕訳日記帳を CSV 出力（対象月、または期首から当月まで）
2. 台帳ブックでアドインを開き **取込** タブ → CSVを選ぶ
3. 差分を確認（月の行をクリックで伝票の内訳）→ **選択した月を差し替える**
4. 差し替え後に同じ差分を取り直し、「一致しています」と表示されれば完了

初回は `import.html` で台帳ブックを作ってもよいですが、以降は **アドインの取込タブ推奨**です
（単体ツールはxlsxを作り直して保存するため、手で加えた書式や他シートの装飾が落ちることがあります）。

## 自動で開く

台帳ブックを開いたときだけ、作業ウィンドウが自動で開きます（他のブックでは開きません）。

- 最初に取込を実行したブックで自動的にONになります（取込タブ「このブックの設定」でON/OFF可能）
- 設定はブック内に保存されるため、**変更後は上書き保存（Ctrl+S）**が必要です
- 仕組み: manifest の `TaskpaneId` を `Office.AutoShowTaskpaneWithDocument` にし、ブック設定 `Office.AutoShowTaskpaneWithDocument = true` を保存
- 既存の台帳ブック（1.0.0.0で作成）は、取込タブでチェックをONにして保存してください

## ダッシュボード

- **全体**: 期間の損益、売上→経常利益の階段グラフ、月次推移（棒クリックで月別へ）、月次損益表（月クリックで月別へ）、費用の大きい科目・売上の相手先（クリックで科目へ）
- **月別**: 前月比つき損益、科目別の当月／前月／増減（クリックで科目へ）、金額の大きい伝票（クリックでExcelの行へ）
- **科目**: 月次推移（棒クリックで月絞り込み）、内訳（摘要から推定した相手先／相手科目／補助科目）、明細の検索（行クリックでExcelの該当行へ）

費用科目の増減は「減った＝緑」で表示します。負の金額は `△` 表記です。

## デプロイ

```
tools/addin/ledgerpilot/ にこのフォルダの中身を配置して push
```
- 更新時は各 `?v=rev_...` と `APP_VERSION`（app.js / import.js）と `CORE_VERSION`（ledger-core.js）を揃えて上げる
- manifest を変えた場合は `%LOCALAPPDATA%\Microsoft\Office\16.0\Wef\` を削除して再登録
- 共通メニュー（slide-menu.js）に載せる場合は `menu.json` に `ledgerpilot/index.html` を追加
