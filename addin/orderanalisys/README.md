# 受注件数分析 Excelアドイン（orderanalisys）

取引先別・グループ別に、受注件数の偏り（累計シェア）とランキング、連携の有無を作業ウィンドウに表示します。グループは「グループ」シートのC列で設定します。

## 配置

カンバンアドインと同じく GitHub Pages に置きます。リポジトリ `tools` の `addin/` の下に、このフォルダをそのまま置いてください。

```
tools/
└─ addin/
   ├─ kanban/
   └─ orderanalisys/        ← このフォルダ
      ├─ index.html         作業ウィンドウ（共有ランタイムの本体）
      ├─ taskpane.js / taskpane.css / core.js
      ├─ commands.html / commands.js   互換用
      ├─ icons/icon-16.png, icon-32.png, icon-80.png
      ├─ manifest.xml
      └─ test/              配置しなくても動きます
```

公開URLは `https://ymatsuda-cmyk.github.io/tools/addin/orderanalisys/index.html` です。push後、ブラウザでこのURLが開けることを確認してから、`manifest.xml` を Microsoft 365 管理センター（統合アプリ）にアップロードします。

※ `test/sheets.json` には取引先データが入っています。公開リポジトリに置く場合は、`test/` フォルダごと除いてください。

## manifest.xml の要点（カンバンとの違い）

- 共有ランタイム（`SharedRuntime 1.1`、`lifetime="long"`）と `FunctionFile = Taskpane.Url` はカンバンと同じです。
- リボンはカンバンのような「ホーム」タブへの追加ではなく、独自タブ「受注分析」に「分析を開く」「グループシート」の2つのボタンを置いています。ホームタブに置きたい場合は、`CustomTab` を `<OfficeTab id="TabHome">` に変え、末尾の `<Label resid="OrderTabLabel"/>` を削除します。
- Id はカンバンと別のものです。更新するときは `Version` を上げてください。

## 動作のしくみ

### 集計の元データ

- 見出し行（先頭15行以内）に「請求先CD」「請求先」「受注件数」があるシートを、自動で集計対象にします。新しい月のシートも、同じ見出しがあれば期間の選択肢に出ます。
- 「受注日」列があるシート（日別）、「グループ」「_グループ名」、「集計_」で始まるシートは対象外です。
- 備考列がない期間（202607など）は、ほかの期間の同じ請求先CDの備考を使って入力起因を判定します。

### グループシート

| 列 | 内容 |
|---|---|
| A 請求先CD | |
| B 請求先 | |
| C グループ名 | ここを編集します。プルダウンで選ぶか直接入力。空欄はまとめません |
| D 受注件数 | 件数がいちばん多い期間の件数（確認用） |
| E 自動入力値 | 非表示。黄色（未確認）の判定に使います |

- 社名から「株式会社」「㈱」、支店名、先頭のコードを除き、同じ社名が2件以上の請求先にグループ名を自動で入れます（「その他」は除外）。
- C列がE列と同じセルは黄色で表示し、書き換えると黄色が消えます。「選んだ行を確認済みにする」「黄色をすべて確認済みにする」でも確認済みにできます。
- 再集計のときに、グループシートにない請求先CDが見つかると末尾に追加し、既存グループと社名が同じならグループ名を自動で入れます。

### 入力起因（G列：備考）による絞り込み

- 備考の値ごとに「入力起因」として分け、作業ウィンドウのドーナツグラフに構成比を表示します。空欄は「手作業（備考なし）」です。INFOMARTから取込・FINETから取込・個人通販から自動作成などの値は、そのまま1つの入力起因になります（新しい値が増えても自動で追加されます）。
- 初期表示は手作業で、外部連携の受注は累計シェアとランキングの対象外です。
- グラフか凡例のボタンを押すと、その入力起因の受注だけで集計し直します（1つずつ切り替え）。

### 集計シートへの出力

`集計_グループ別_<入力起因>_<期間>`（または `集計_請求先別_…`）シートに、選んでいる入力起因の全件の表と、グラフ3つ（入力起因の構成比、上位20のランキング、上位100までの累計シェア）を出力します。シート名は31文字までに切り詰めます。同名のシートがあれば作り直します。

## 必要な環境

ExcelApi 1.7 以上。C列のプルダウン（入力規則）と、アドイン自身の書き込みでの変更検知の停止は ExcelApi 1.8 以上で動きます。1.7 の環境ではプルダウンなしで直接入力します。
