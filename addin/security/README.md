# 情報漏洩対策集（Excelアドイン）

`taskpane.html` が、アドインの画面（情報漏洩対策集のアプリ本体）です。Excelの作業ウィンドウで「対策を見る › 点検する › 可視化」を行い、**データの保存先はExcelのブック**です。`manifest_security.xml` は、共有ランタイムの設定を含む最新版（公開先 `https://ymatsuda-cmyk.github.io/tools/addin/security/`）に合わせてあります。

## 配置するファイル

公開先フォルダ `tools/addin/security/` に、次の3つをそのまま置きます。

```
tools/addin/security/
├─ taskpane.html      アドインの画面（アプリ本体。単一ファイル）
├─ manifest_security.xml       アドインの定義（Excelに読み込ませる）
└─ assets/            リボン用アイコン（icon-16 / 32 / 64 / 80）
```

公開後、`https://ymatsuda-cmyk.github.io/tools/addin/security/taskpane.html` がブラウザで開けることを確認してください（ブラウザでも動きます。その場合の保存先はブラウザ内です）。

## 保存の仕組み

| 何を | どこに | いつ |
|---|---|---|
| 対策・取引先・対象判定・点検結果のすべて | ブックの非表示シート `_data`（JSON） | 画面で変更するたびに自動（約1秒後） |
| 見やすい表（`漏洩_サマリ`／`漏洩_対策一覧`／`漏洩_取引先`／`漏洩_対象判定`／`漏洩_点検結果`／`漏洩_要対応`） | 「漏洩_」で始まる6枚のシート | 「データ管理 › Excelの表を更新」を押したとき（任意で変更の12秒後に自動） |

- 入力は画面（作業ウィンドウ）で行います。「漏洩_」シートは**出力専用**で、アドインが作り直すため、Excel側で編集しても反映されません。自分用の計算は別のシートに書いてください。
- `_data` はブックと一緒に保存されます。デスクトップ版Excelでは、通常どおりブックを保存（Ctrl+S）してください。Excel on the web は自動保存です。
- ブックを開き直してアドインを開くと、`_data` から前回の続きを読み込みます。別のブックで開くと、そのブックのデータが読み込まれます（ブックごとに独立）。
- 以前のバージョンで作られた「サマリ」「対策一覧」などのシートは使わなくなったので、不要なら削除してください。`_data` は引き続き読めます。

## ブックを開いたときに自動で開く（共有ランタイム）

マニフェストには共有ランタイム（`SharedRuntime 1.1`、`lifetime="long"`）が設定されています。これにより、作業ウィンドウを閉じてもアドインの処理が動き続け、保存や自動更新が途切れません。

ブックを開いたときに自動で画面を開くには、ブックごとに1回、画面の「データ管理 › Excelへの保存」で **「ブックを開いたときに、自動でこの画面を開く」** にチェックを入れます（設定はそのブックに保存されます）。解除も同じ場所でできます。

共有ランタイムに対応していない環境（古い版のExcelなど）では、マニフェストの追加時に「このアドインは使えません」と表示されることがあります。

## Excelへの追加（サイドロード）

- **Excel on the web**：挿入 › アドイン › 個人用アドインのアップロード › `manifest_security.xml` を選択
- **Windows版Excel**：manifest_security.xml を置いたフォルダを共有フォルダにし、ファイル › オプション › トラストセンター › 信頼できるアドインカタログ に共有パスを登録 › Excelを再起動 › 挿入 › 個人用アドイン › 共有フォルダー
- **Mac版Excel**：`~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/` に manifest_security.xml をコピー › Excelを再起動 › 挿入 › 個人用アドイン
- **社内配布**：Microsoft 365 管理センター › 統合アプリ からマニフェストを展開

追加すると「ホーム」タブに「情報漏洩対策 › 対策集 連携」ボタンが出ます（ボタン名とツールチップは、マニフェストの文言のままです）。

## 使い方

1. 「対策を見る」で起因ごとの原因・対策・点検方法を確認（追加・編集もここ）
2. 「点検する」で取引先を選び、起因ごとの対象判定の設問に答え、点検項目を「OK／要対応／対象外」で記録
3. 「可視化」で進捗・要対応・取引先×起因のマトリクスを確認
4. 「データ管理」で取引先の追加、Excelの表の更新、JSONバックアップ

作業ウィンドウが狭い場合は、幅をドラッグして広げると見やすくなります（起因の一覧は狭いときはボタン状に折り返します）。

## うまく動かないとき

- エラーには「どの段階で失敗したか」が表示されます（例：「データの書き込みでエラー：…」）。その文言をそのまま共有してください。
- 「一部の書式は適用できませんでした：…」と出た場合、データは保存されています。表・色分け・グラフなど、Excelの版によって使えない装飾だけが省かれています。
- 「Excelの保存データを読み込めていないため、自動保存を止めています」と出た場合は、保存データが壊れているか読めない状態です。JSONバックアップから戻すか、「今すぐExcelに保存」で現在の画面の内容に上書きしてください。
- 更新したファイルを置き直したあとも古い画面が出る場合は、作業ウィンドウを閉じて開き直してください。それでも変わらない場合は、アドインを削除して追加し直すか、Officeのキャッシュを削除します（Windows：`%LOCALAPPDATA%\Microsoft\Office\16.0\Wef\`、Mac：`~/Library/Containers/com.microsoft.Excel/Data/Library/Caches/`）。
