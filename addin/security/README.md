# 情報漏洩対策集 連携（Excelアドイン）

Webページ「情報漏洩対策集」のデータ（JSON）をExcelに保存し、Excelで入力した点検結果をページに戻すためのアドインです。

## ファイル構成

```
manifest.xml      アドインの定義（Excelに読み込ませるファイル）
taskpane.html     作業ウィンドウの画面
taskpane.js       Excelへの書き込み・読み取り処理
taskpane.css      画面の見た目
assets/           リボン用アイコン
```

## 1. 公開（GitHub Pages の例）

Officeアドインは HTTPS で配信されている必要があります。

1. このフォルダは `ymatsuda-cmyk/tools` リポジトリの `addin/security/` に置いてある（GitHub Pages で公開される）
2. 公開URL：`https://ymatsuda-cmyk.github.io/tools/addin/security/`
3. `manifest.xml` のURLはこの公開URLに合わせて設定済みなので、置き換えは不要

公開先を変える場合は、`manifest.xml` 内の `https://ymatsuda-cmyk.github.io/tools/addin/security` をすべて置き換えてください。

## 2. Excelへの追加（サイドロード）

- **Excel on the web**：挿入 › アドイン › 個人用アドインのアップロード › `manifest.xml` を選択
- **Windows版Excel**：manifest.xml を置いたフォルダを共有フォルダにし、ファイル › オプション › トラストセンター › 信頼できるアドインカタログ に共有パスを登録 › Excelを再起動 › 挿入 › 個人用アドイン › 共有フォルダー
- **Mac版Excel**：`~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/` に manifest.xml をコピー › Excelを再起動 › 挿入 › 個人用アドイン
- **社内配布**：Microsoft 365 管理センター › 統合アプリ からマニフェストを展開

追加すると「ホーム」タブに「情報漏洩対策 › 対策集 連携」ボタンが出ます。
ExcelApi 1.8 以上（Microsoft 365 版のExcel）が必要です。

## 3. 使い方

| やりたいこと | Webページ | Excelアドイン |
|---|---|---|
| Excelに保存 | データ管理 › 「JSONをコピー」 | 「1. Excelに保存する」に貼り付け › 保存 |
| Excelで点検を入力 | — | 「点検結果」「対象判定」「取引先」シートのプルダウン・メモ・点検日を入力 › 「集計を更新」 |
| ページに戻す | データ管理 › 貼り付け › 「置き換えて読み込む」 | 「3. JSONに書き出す」（自動でコピー） |

### 作成されるシート

- **サマリ**：対象社数・実施率・要対応・未点検、起因別のグラフ、取引先×起因のマトリクス
- **対策一覧**：起因ごとの概要・設問・原因・対策・点検方法・参考資料（閲覧用）
- **取引先**：点検対象（はい／いいえ）を入力
- **対象判定**：取引先×起因の設問に回答（はい／いいえ）
- **点検結果**：結果（OK／要対応／対象外／未点検）・メモ・点検日を入力
- **要対応**：要対応の項目の一覧
- **_data**（非表示）：データの原本（JSON）。削除・編集しないでください

### 注意

- 保存・集計更新のたびに、上記の名前のシートは作り直されます。自分用のメモや計算は別のシートに書いてください。
- 起因・対策・点検項目の追加や編集は Webページ側で行います（Excelの「対策一覧」の編集は戻りません）。
- 列名や、非表示の ID 列は変更しないでください。読み取りに使っています。
- 判定・要対応・サマリは「集計を更新」を押した時点の内容です。
