# addin/schedule — 期スケジュール（Excel「計画シート」連携）

メニューの「スケジュール」を押すと、**画面遷移せずに**ポップアップ（Officeダイアログ）で `app.html` が開きます。
ポップアップの変更は、ブックの `計画シート`／`計画マスタ` に書き込まれ、Excelの共同編集で他の人が変えた内容もポップアップに反映されます。

## 構成（common に持たせた部分）
| ファイル | 場所 | 役割 |
|---|---|---|
| `slide-menu.js` | `addin/common/` | メニュー項目に `popup` 指定があれば、遷移せずにダイアログで開く（起動の仲介もここ） |
| `schedule-bridge.js` | `addin/common/` | Excelの読み書き、差分マージ、イベント監視。初回クリック時に自動で読み込む |
| `menu.json` | `addin/common/` | `スケジュール` を `popup` 指定の項目にした版 |
| `app.html` | `addin/schedule/` | スケジュール本体（ポップアップの中身） |

```
メニュー「スケジュール」（slide-menu.js）
  → 今開いているページ（カンバン等）が仲介役になり、schedule-bridge.js でExcelを読み書き
  → ポップアップ（app.html?excel=1）を開く
```

## リポジトリへの置き方
1. `addin/common/` の `slide-menu.js`・`schedule-bridge.js`・`menu.json` を差し替え／追加する。
2. `addin/schedule/app.html` を追加する。
3. GitHub Pages に反映されたら、メニューの「スケジュール」（右に ⧉ の印）が、ポップアップで開く。

マニフェストの変更は不要です。ポップアップのURLが、メニューを開いているページと同じドメイン（`ymatsuda-cmyk.github.io`）だからです。

## menu.json の書き方（popup 項目）
```json
{ "id": "schedule", "label": "スケジュール", "icon": "",
  "popup": "https://ymatsuda-cmyk.github.io/tools/addin/schedule/app.html",
  "width": 95, "height": 92 }
```
- `url` の代わりに `popup` を書く。`width`・`height` は画面に対する%（省略時 95・92）。
- シート名を変えたいときは、`"sheetName"`（既定 `計画シート`）、`"masterName"`（既定 `計画マスタ`）を足す。
- 古い `slide-menu.js` を読み込んでいるページでは、この項目を押しても何も起きません（`url` が無いため）。各ページの `slide-menu.js` は共通ファイルなので、差し替えれば全ページに反映されます。

## 動き
- 初回に、ブックへ `計画シート` と `計画マスタ` を自動で作ります。**既存のシート（wbs・体制・顧客マスタなど）には触れず、イベント監視もこの2シートだけ**です。
- 画面で変更すると、変更したセルだけを書き込みます。他の人が同時に変えた別のセルは上書きしません。
- Excelでこの2シートのセルを直接編集すると、ポップアップに反映されます。
- DialogApi 1.2（ホスト→ポップアップの送信に使う）に未対応のExcelでは、その旨を画面下に表示して開きません。

## 注意
- 仲介役は「メニューを開いているページ」です。そのページを閉じる、または別のツールへ移動すると、ポップアップも閉じます（連携が切れるため）。
- 同じページから開けるポップアップは1つまでです。
- ブックは OneDrive／SharePoint に置く（共同編集のため）。
- この環境にはExcelがないため、`Excel.run` を使う部分は実機では未確認です。同期の仕組みは、疑似Excelに対するテストで確認済みです。

## 実機での確認チェックリスト
1. メニューの「スケジュール」を押しても画面が遷移せず、ポップアップが開き、「Excel（計画シート）に接続しました」と出る。
2. ブックに `計画シート`・`計画マスタ` が作られ、既存シートに変化がない。
3. 画面で予定を追加すると1行増え、工数を変えるとその行の「入力値」だけが変わる。
4. 2人（または2つのウィンドウ）で開き、一方が `計画シート` のセルを書き換えると、もう一方に反映される。
5. ポップアップを開いたまま、メニューから別のツール（営業報告など）へ移動すると、ポップアップが閉じる。
6. `wbs` シートの重い計算（数式）で、ポップアップの動きが遅くならない。
