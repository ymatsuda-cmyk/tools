# Change Log

## 1.1.0 - 2026-09-02

### LLM connection management and list controls

- Replaced one-model profiles with connections that can hold multiple models, including automatic migration of existing settings.
- Added quick switching of registered models from the active-model display.
- Added a tag visibility control to the list toolbar; tags are displayed by default.
- Enabled month navigation during bulk permission assignment and added a control to return to the full-period view.
