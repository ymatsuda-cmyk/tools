# inkboard 手書きボードAPI

iPad の Apple Pencil・指・マウスで描ける手書きボードの共通APIです。
用紙固定（A3／A4／A5／B5／16:9／4:3、縦横）と無限キャンバスに対応し、
参照表示（埋め込み先の小さな表示）をタップすると全画面の編集画面が開きます。
手書きに加えて、図形・矢印・文字を置いてフロー図を描け、グループにまとめられます。

```
api/inkboard/
├── inkboard.js    呼び出す側が使う入口（ESモジュール。依存ライブラリなし）
├── inkboard.css   参照表示と全画面の見た目
└── index.html     確認用のデモ
```

## 使い方

```js
import { createBoard, renderBoard } from 'https://cdn.jsdelivr.net/gh/ymatsuda-cmyk/tools@main/api/inkboard/inkboard.js'
// CSS も読み込む: https://cdn.jsdelivr.net/gh/ymatsuda-cmyk/tools@main/api/inkboard/inkboard.css

const value = createBoard({ paper: 'A4', orientation: 'portrait' })  // 無限キャンバスは { paper: 'infinite' }
const board = renderBoard(el, value, { onChange: (v) => save(v) })
```

`onChange` を渡さなければ閲覧のみ（全画面でも描けない）になります。

## API

| 関数 | 内容 |
|---|---|
| `createBoard({ paper, orientation, background })` | 新しい値を作る。`paper` は `infinite` `A3` `A4` `A5` `B5` `W169` `W43`、`background` は `plain` `grid` `lines` `dots` |
| `renderBoard(container, value, options)` | 参照表示を描く。戻り値は `{ value, update(v), open(), destroy() }` |
| `openBoard(value, options)` | 全画面の編集画面だけを開く。閉じたときの値で解決する Promise を返す |
| `previewArea(value)` | 参照表示で見せる範囲 `{x, y, w, h}`。埋め込み先の枠の縦横比を合わせるのに使う |
| `exportImage(value, { area, scale, type })` | 画像（既定は PNG）の Blob を作る |
| `parseBoard(value)` ／ `serializeBoard(data)` | 値とデータの相互変換 |
| `SHAPES` | 使える図形の一覧（この定数があれば図形に対応した版） |

`renderBoard` の options：`onChange` `onOpen` `onClose` `clickToOpen`（既定 true）`emptyText` `title` `changeDelay`（既定 800ms）`prefs` `onPrefsChange`。
`onChange` は線を書くたびではなく、書き終えてから `changeDelay` 待って呼びます。閉じたとき・タブを隠したときは待たずに呼びます。

`prefs`（オブジェクトか、それを返す関数）と `onPrefsChange` を渡すと、パレットの色・グリッド吸着・パレットの出し方・閉じるボタンの位置などを
呼び出し側で保存して端末間で共有できます。渡さなければ localStorage（`inkboard.prefs`）だけに保存します。
「Pencil を使ったか」「指で描くか」「パレットの位置」はその端末だけの設定として共有しません。

## 値の形式

改行を含まない1行のJSONです。Markdown のコードブロックや表のセルにそのまま置けます。

```json
{"v":1,"mode":"paper","paper":"A4","orient":"portrait","bg":"plain","view":[40,80,600,340],
 "s":[["pen","#1f1f1f",3,"AAg…",{"p":"r1"}]],
 "o":[{"k":"r","id":"r1","t":"rect","x":0,"y":0,"w":120,"h":64,"c":"#1f1f1f","f":"w","lw":2,"tx":"受付"},
      {"k":"l","id":"l1","a":{"x":120,"y":32,"s":"r1","sd":"r"},"b":{"x":300,"y":32},"sh":"s","hd":"e","c":"#1f1f1f","lw":2}]}
```

- `view` は参照表示の範囲（世界座標）。`null` なら用紙全体、無限キャンバスは描いた線と図形の全体を表示します
- `s` は手書きの線 `[道具, 色, 太さ, 点列, 追加情報]`。点列は「x, y, 筆圧」を前の点との差分にして、1文字5ビットの可変長で詰めた文字列です（座標は 1/4px 単位、筆圧は 0〜63）。
  追加情報は省略でき、`p`（中に書いた図形の id）`g`（グループ）`lk`（ロック）を持ちます
- `o` は図形・線・文字（無ければ省略）
  - 図形 `k:"r"`：`t` は `rect`（角丸の四角）`round`（開始・終了）`diamond` `ellipse` `para`（入出力）`doc` `cyl` `note` `frame`（枠）。`f` は塗り（`""` なし、`"w"` 白、色）、`d` は点線、`tx` `tc` `fs` は中の文字
  - 線 `k:"l"`：`a` `b` が両端。`s` と `sd`（`t` `r` `b` `l`）があれば図形の辺につながっていて、図形を動かすと追従します。`sh` は `s` 直線・`e` カギ線・`c` 曲線、`hd` は `e` 片矢印・`b` 両矢印・`n` なし
  - 文字 `k:"t"`
  - どれも `g`（グループ。外側から順の id の配列）と `lk`（ロック）を持てます
- 旧版の値（`o` も追加情報も無いもの）はそのまま読めます。**旧版の inkboard.js で新しい値を保存すると図形が消える**ので、呼び出し側は `SHAPES` の有無で判断して、旧版のときは閲覧のみにしてください

## 編集画面の操作

画面いっぱいがキャンバスで、上に浮かぶパレット（左端のつまみで移動、ダブルクリックで元の位置）と左下の閉じるボタンだけを出します。

| 操作 | 方法 |
|---|---|
| 描く | Apple Pencil（筆圧で太さが変わる）、マウス。「指で描く」がオンなら指1本でも |
| 移動 | 指1本（「指で描く」がオフのとき。図形・線・文字に触れるとそれを動かす）、2本指、Space＋ドラッグ、ホイール、「移動ツール」 |
| 拡大縮小 | 2本指のピンチ、⌘／Ctrl＋ホイール、＋／−、0 で全体表示 |
| 道具 | P ペン、M マーカー、E 消しゴム（手書きの線ごと消す）、V 選択、S 図形と線、T 文字、R 参照表示の範囲、H 移動 |
| 色 | パレットの色をタップ。長押し（右クリック）で変更・削除、＋ で追加（12色まで）。選んだものがあればその色を変える |
| 図形 | 図形ボタンから種類を選び、タップで置く・ドラッグで大きさを決める。選んだ図形の四辺の ＋ から引っ張ると矢印、別の図形の上で離すとつながる |
| 線 | 図形ボタンの線（直線／カギ線／曲線）を選んでドラッグ。図形の上から始めても終えてもつながる |
| 文字 | 文字ツールでタップ。図形はダブルタップ（Enter）で中に文字を書ける。ペンで図形の中に書いた線は図形と一緒に動く |
| 選ぶ | 選択ツールで囲む、または物をタップ。ドラッグで移動、四隅で拡大縮小、矢印キーで少しずつ動かす |
| 選んだものの操作 | 浮かぶメニューか、⌘C コピー・⌘X 切り取り・⌘V 貼り付け・⌘D 複製・Delete 削除・⌘A すべて選ぶ |
| 貼り付け | 何もない所をタップすると「ここに貼り付け」 |
| グループ | ⌘G でグループ化、⇧⌘G で解除。ダブルタップでグループの中へ（何もない所をタップで抜ける）。入れ子にできる |
| その他 | ロック、前面へ・背面へ、塗り（なし・白・薄い色） |
| グリッド吸着 | パレットのグリッドボタン（G）。オンのとき図形・移動・大きさが24pxの格子にそろう |
| 元に戻す | ⌘Z、やり直す ⇧⌘Z。指では2本指タップで元に戻す、3本指タップでやり直す |
| 閉じる | 閉じるボタン（ペン先では反応しません）、Esc（選んでいるときは選択を外す） |

「…」の中で、パレットを「常に表示」か「ペンで表示」（Pencil が触れると出て、しばらくすると丸く縮む）に切り替え、
閉じるボタンを左下・右下から選べます。用紙・背景・指で描く・参照表示の範囲・すべて消すもここにあります。

「指で描く」は初期状態でオフです。指は移動・拡大縮小に使い、ペンなどの道具のままでも、指で図形・線・文字に触れればそのまま動かせます（手書きの線や何もない所を触ると画面の移動）。図形のダブルタップで中の文字を編集できます。
Pencil で描いている最中と直後の指の入力も無視します。選択・図形・文字のツールでは、指で物をタップして選んだり動かしたりできます。
