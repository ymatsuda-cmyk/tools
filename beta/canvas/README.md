# 共有ボード（手書き・テキスト・図）

iPad・Mac・Windows のブラウザで、社内メンバーが同じボードに同時に描き込めるアプリです。手書き、テキスト、図形とそれをつなぐ線を扱えます。

- 画面：GitHub Pages（`index.html` 1枚）
- 中継：Google Apps Script（`Code.gs`）
- 保存先：GitHub の private リポジトリ（`boards/<ボード名>.json`）

## 仕組み

1. 同じボードを開いている端末どうしは、WebRTC で直接つながります（接続まで5〜10秒）。つながった相手には、描いている途中の線・図形の移動・カーソル位置が0.1秒前後で届きます。
2. すべての操作は GAS にも送られ、連番が振られます（GAS のキャッシュに6時間保持）。ここで決まった順番が正式な状態になります。
3. 直接つながらない相手（社内ファイアウォールなど）とは、これまで通り GAS 経由で1〜3秒ごとに同期します。切り替えは自動です。
4. GAS のトリガーが1分ごとに、変更のあったボードを private リポジトリへコミットします。

直接接続の相手がいるときは、GAS への問い合わせを5秒間隔に減らします。

GitHub のトークンは GAS 側だけに置くので、公開される `index.html` には秘密情報が入りません。

## セットアップ

### 1. 保存用の private リポジトリ
1. GitHub で private リポジトリを作成（例：`writerm/board-data`）。README 付きで作っておくと main ブランチができます。
2. Settings → Developer settings → Fine-grained tokens で、そのリポジトリだけを対象に **Contents: Read and write** のトークンを発行。

### 2. GAS
1. https://script.google.com で新しいプロジェクトを作り、`Code.gs` の内容を貼り付け。
2. プロジェクトの設定 → スクリプト プロパティに追加：

   | プロパティ | 値 |
   |---|---|
   | `GITHUB_TOKEN` | 発行したトークン |
   | `GITHUB_REPO` | `owner/repo` |
   | `GITHUB_BRANCH` | `main`（省略可） |
   | `BOARD_DIR` | `boards`（省略可） |
   | `TEAM_KEY` | 社内で共有する合言葉（長めのランダム文字列を推奨） |

3. エディタで関数 `setup` を選んで実行（権限を承認）。設定チェックと1分ごとの保存トリガー登録を行います。
4. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 表示された `…/exec` の URL を控える

`Code.gs` を直したときは「デプロイを管理 → 編集 → 新バージョン」で更新すると URL が変わりません。

### 3. GitHub Pages
1. 画面用の別リポジトリ（public で可）に `index.html` を置く。
2. Settings → Pages → Branch を `main` / root にして公開。
3. 開いて右上の設定に、表示名・GAS の URL・チームキーを入力。

メンバーには「その他 → このボードのリンクをコピー」で URL を共有し、各自の端末でも設定に URL とチームキーを入れてもらいます。

## 使い方

| 操作 | iPad | Mac / Windows |
|---|---|---|
| 図形 | 図形ツールでタップ（標準サイズ）またはドラッグ。作るとすぐ文字を入力できます | 同左（R） |
| 図形をつなぐ | 線でつなぐツールで、図形から図形へドラッグ。図形を動かすと線も追従します | 同左（L） |
| 選択・移動 | 選択ツールでタップして選択、ドラッグで移動。図形は右下の四角で大きさを変更 | 同左（V）。Delete で削除、Enter で文字を編集 |
| グリッドに合わせる | 補助バーの「グリッド」、または「その他」メニューで切り替え | G キーで切り替え。Option/Alt を押している間だけ一時的に反転 |
| 図形の文字 | 選択中の図形をもう一度タップ、またはテキストツールで図形をタップ | ダブルクリック |
| 描く | Apple Pencil（筆圧対応） | マウス・ペンタブレット |
| 移動 | 指1本でドラッグ | スペース＋ドラッグ／スクロール／中ボタン |
| 拡大縮小 | 2本指でピンチ | ⌘/Ctrl＋スクロール、トラックパッドのピンチ |
| テキスト | テキストツールでタップ。既存の文字はタップで編集、ドラッグで移動 | 同左。⌘/Ctrl＋Enter または Esc で確定 |
| 元に戻す | トレイの ↶ | ⌘/Ctrl＋Z |
| ツール切替 | — | V 選択／P ペン／M マーカー／T テキスト／R 図形／L 線でつなぐ／E 消しゴム／H 移動／1〜3 太さ／0 全体表示 |

- iPad で初めて Pencil を使うと、指は移動・拡大用に切り替わります（その他 → 指で描く で変更可）。Pencil で書いている間は手のひらの接触を無視します。
- 選択中に色をタップすると、その要素の色が変わります。補助バーから図形の種類・塗り・矢印の向きも変えられます。
- 「グリッドに合わせて配置」をオンにすると、図形・テキストの移動、図形の作成と大きさ変更、線の端点がグリッドに吸着します。手書きの線は形を保ったまま、グリッド間隔単位で動きます。
- グリッド間隔は「その他」メニューで 5〜100px の間で変えられます。表示は点・罫線（5マスごとに太線）・なしから選べます。この設定は端末ごとに保存されます。
- 図形をつなぐ線は、標準で滑らかな曲線になり、図形どうしのすき間が広い方向（左右か上下）の辺の中央から出入りします。補助バーで直線にも切り替えられます。
- 線でつないだ線の端は、選択して端の丸をドラッグすると別の図形につなぎ替えられます。
- 右上のアバターに緑の点がある人とは直接つながっています。他の人のカーソルは「その他」から非表示にできます。
- ホーム画面に追加すると、全画面のアプリのように使えます。

## 制限と目安

- 直接接続は、端末の通信経路を調べるために Google の公開 STUN サーバー（stun.l.google.com）を使います。描いた内容は STUN サーバーを通りません。社内規定で外部への接続が制限されている場合は、設定の「端末どうしを直接つないで速く同期する」を外すと GAS 経由だけになります。
- 中継サーバー（TURN）は使っていないため、ネットワークによっては直接つながりません。その場合も GAS 経由で同期は続きます（1〜3秒遅れ、描いている途中の線は見えません）。
- 直接接続は全員が全員とつながる方式のため、快適なのは 10人程度までです。GAS の同時実行数（1アカウントあたり約30）も上限になります。
- 未保存の操作は GAS のキャッシュに6時間保持され、1分ごとに GitHub へ保存されます。トリガーが止まっていないか、GAS の「トリガー」画面で確認できます。
- 1つのボードが数MBを超えると読み込みが遅くなります。テーマごとにボードを分けるのがおすすめです。
- チームキーを知っている人は誰でも読み書きできます。退職者が出た場合などはキーを変更してください。
