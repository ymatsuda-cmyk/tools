# PostPilot セットアップ手順

キーワードからネタを集め、AIが採点・下書きを作り、承認したものを予約時刻にXへ投稿するアプリです。Google Apps Script（GAS）だけで動きます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Code.gs` | サーバー処理（収集・採点・生成・予約投稿・X連携・データ保存） |
| `index.html` | 画面（投稿ボード／承認／設定） |
| `appsscript.json` | タイムゾーン（Asia/Tokyo）・Webアプリ公開設定・権限 |

データは自動で作られるスプレッドシート（`accounts` / `items` / `drafts` / `logs` の4シート）に保存されます。APIキーとXのトークンはスクリプトプロパティに保存し、シートには書きません。

## 1. 事前に用意するもの

1. **AIのAPI URL**：投稿文の採点・作成に使うAIの接続先です。次のどれでも使えます。
   - **自前のLLMサーバー**：vLLM・LM Studio・Ollama などをngrokなどで公開したURL（例：`https://xxxx.ngrok-free.app`）
   - **Anthropic公式API**：URLは空欄のままにして、APIキーだけ登録します
   - GASはGoogleのサーバーから呼び出すため、`localhost` のURLは届きません。必ず外から見えるURLにしてください。
2. **X Developer のアプリ**
   - User authentication settings で App permissions を **Read and write** にします。
   - Callback URI は必須項目なので、任意のURL（例：`https://example.com`）を入れておきます。PIN方式で連携するため、実際には使いません。
   - Keys and tokens の **API Key と API Key Secret（Consumer Keys）** を控えます。
   - 料金プランごとの投稿上限を確認しておいてください。

## 2. GASプロジェクトを作る

1. Googleスプレッドシートを新規作成し、「拡張機能 → Apps Script」を開きます。
2. `Code.gs` の中身を貼り付けます。
3. 「ファイル → ＋ → HTML」で `index` という名前のファイルを作り、`index.html` の中身を貼り付けます。
4. 「プロジェクトの設定」で「appsscript.json をエディタで表示」をオンにし、`appsscript.json` の中身を貼り付けます。
5. エディタで `testWeighted` を一度実行し、権限を許可します。

## 3. Webアプリとして公開

1. 「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」を選びます。
2. 実行ユーザーは「自分」、アクセスは「自分のみ」にします（manifest の設定どおり）。
3. 発行されたURLを開きます。スマホのホーム画面に追加しておくと承認が楽です。

コードを更新したら「デプロイを管理 → 編集 → 新バージョン」で反映します。

## 4. アプリ内の初期設定

1. **設定 → 全体の設定** で次の項目を入力して保存します。
   - AIのAPI URL・APIの形式（通常は「URLから自動判定」）・モデル名（例：`qwen3:14b`）
   - APIキー（サーバー側で認証をかけている場合のみ）
   - 保存後に「AIの接続テスト」を押し、「接続できました」と出ればOKです
   - X API Key / Secret
   - モデル名（初期値のままでOK）
2. **設定 → アカウントを追加** で、名前・キーワード・ペルソナ・ターゲット・投稿時刻などを入れて保存します。
3. 「Xと連携」を押して開いた画面で、**投稿したいXアカウントでログインして許可**します。表示されたPINを入力して「PINで連携を完了」を押します。アカウントごとにこの手順を繰り返します。
   - 別アカウントを連携するときは、先にブラウザのXからログアウトするか、シークレットウィンドウで許可画面を開いてください。
4. 「保存済みの設定でテスト生成」を押して、承認待ちに下書きが出れば準備完了です。
5. 問題なければ「自動実行を有効にする」をオンにして保存します。収集は指定間隔ごと、予約投稿の確認は5分ごとに実行されます。

## 5. Xアカウント側の設定

各アカウントの「設定 → アカウント情報 → 自動化」で、管理アカウントを登録して **「自動化アカウント」ラベル** を付けてください。Xの自動化ルールで求められています。

## 動きの仕組み

1. **収集**：キーワードごとのGoogleニュースRSS（直近3日）と追加RSSから記事を集めます。同じURLは除外し、設定がオンなら他アカウントで使ったネタも除外します。
2. **採点**：未使用のネタをAIが0〜100点で採点します。最近の投稿と被らないことも評価に含めます。
3. **生成**：60点以上の上位ネタを、空いている投稿枠の数だけ下書きにします。文字数はXの数え方（全角＝2）で280以内かをチェックします。
4. **承認**：承認モードが「毎回承認」なら承認待ちに入ります。「全自動」なら直接予約されます。
5. **投稿**：予約時刻を過ぎた下書きを投稿し、失敗した場合は理由を表示します。

## よくあるつまずき

- **X API 401 / 403**：アプリの権限が Read and write になっていない可能性があります。権限を変えたあとは、アカウントの連携をやり直してください。
- **AI API 404**：URLのパスかモデル名が違います。APIの形式を明示的に選ぶか、モデル名をサーバーにあるものに合わせてください。
- **「AI APIの応答がJSONではありません」**：サーバーが止まっているか、ngrokのURLが変わっています。ngrokの無料版はURLが起動のたびに変わるので、そのたびに設定画面のURLを更新してください。
- **生成が途中で失敗する**：大きなモデルだと応答に時間がかかり、タイムアウトすることがあります。小さめのモデルにするか、「1回の収集で作る下書き数」を減らしてください。
- **思考モデル（Qwen3など）**：出力に含まれる `<think>…</think>` は自動で取り除きます。
- **「別の処理が実行中です」**：自動収集の実行中です。1〜2分待ってから再度押してください。
- **アカウントが多いと処理が止まる**：GASの1回の実行時間は6分までです。アカウントが多い場合は、「1回の収集で作る下書き数」を減らすか、収集間隔を短くしてください。
- 実行の記録はスプレッドシートの `logs` シートで確認できます。

## 設定の同期（JSONBin・暗号化）

設定画面の「設定の同期」で、次の内容をまとめてパスフレーズで暗号化し、JSONBinに保存できます。

- AIのAPI URL・形式・キー・モデル名
- XのAPI Key／Secret
- 各アカウントの設定とXの連携情報

暗号方式はMemoStockと同じです（PBKDF2-SHA256 60万回 → AES-GCM 256bit）。暗号化と復号はブラウザの中で行うので、JSONBinには暗号文しか送られません。パスフレーズはどこにも保存しません。

- **保存**：JSONBinのキーとパスフレーズを入れて「暗号化して JSONBin に保存」を押します。初回はBinが自動で作られ、Bin IDが表示されます。
- **読み込み**：別のPostPilot（別のGoogleアカウントや作り直したデプロイ）で、JSONBinのキー・Bin ID・同じパスフレーズを入れて「JSONBin から読み込んで反映」を押します。
- 同じWebアプリをPCとスマホで開く場合、設定はもともとサーバー側で共有されているので、同期は不要です。
- 自動実行のオン／オフはデプロイごとの設定なので、読み込み後に改めてオンにしてください。
