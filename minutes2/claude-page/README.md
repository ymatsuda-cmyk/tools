# claude-page — 「Claude.ai で要約待ちを変換」で開くページ

Claude.ai に公開した Artifact「MinutesStock 要約待ちを要約する」（`src/config.js` の `CLAUDE_DEFAULT_URL`）の元のファイルです。
ClipStock の同じ名前のページと同じ作りで、Notion の作業DB「議事録 要約作業」の要約待ちを、Claude が要約して Notion に書き込みます。
Mac が5分以内に回収して、議事録アプリに反映します（書き込む形は `mac/minutes_worker.py` の `summary_json` が読む、ページ末尾の json コードブロック1つ）。

## 開き方（議事録アプリから）
- 変換管理の「Claude.ai で要約待ちを変換」→ `…#run`：要約待ちをすべて、すぐに要約する
- 会議の「Notion 経由で要約する」→ `…#m-<会議ID>`：その会議だけ、すぐに要約する
- ハッシュ無し（ブックマークなど）：一覧を出すだけ。選んで「要約する」を押す
- 設定で自分のリンク（Claude のプロジェクトなど）を入れているときは、そのリンクを開くだけで、自動では始まらない

## 作りの要点
- 一覧は、作業DBの保存済みビュー（`view://…`）から読む。Notion の SQL・rows の問い合わせ回数の上限を受けない（ビューが使えないときだけ rows に切り替える）
- 字数・会議日時は、各ページを裏で読んで数える（Notion の回数制限の対象外）。要約の直前には、必ず読み直す
- 書き込みは、json コードブロックを1回で追加 → 読み直して最後まで入ったか確認 → 状態を「要約済み」に。前回の書き込みが残っているときは、完全ならそれを使って状態だけ直し、途中で切れているときは止めて知らせる（Mac は、ページ内のコードブロックをすべてつなげて読むため、2つ入ると読めなくなる）
- 長い文字起こしは、UTF-8 で約200KBまでに切って送り、要約の末尾に注記する（Claude への依頼は全体で256KiBまで）
- 実在しない時刻は、書き込む前に消す

## 公開し直すとき
Claude のチャットで、このファイルを同じ Artifact（上の URL）に公開し直す（URL と、Notion・Claude を使う許可の設定は引き継がれる）。
