# DashboardBar（Python版） v2.0.1

ダッシュボードを Windows の画面の端にサイドバーとして常時表示するツールです。
画面の端に専用の領域を確保するため、他のウィンドウを最大化しても、ダッシュボードとは重なりません。

- ダッシュボードは Edge のアプリモードで表示します
- python.exe と Edge だけで動くため、スマートアプリコントロール（SAC）をオンにしたまま使えます
- 標準ライブラリだけで動くので、追加のインストールは不要です

---

## v2.0.1 の新機能

| 機能 | 内容 |
| --- | --- |
| タスクトレイ常駐 | トレイのアイコンから、展開／収納・再読み込み・設定・更新の確認・終了を操作できます |
| 設定画面 | `settings.json` を手で編集しなくても、画面から設定を変えられます |
| モニターと左右の選択 | 表示するモニターと、左端・右端のどちらに置くかを選べます |
| 二重起動の防止 | すでに起動している場合は、新しく起動せずに既存の帯を表示します |
| 全画面アプリで自動退避 | 動画やプレゼンなどを全画面で表示している間は、帯ごと隠れます |
| 自動復旧 | ダッシュボードのウィンドウを閉じてしまっても、自動で開き直します |
| 自動起動と状態の復元 | Windows の起動時に自動で起動できます。前回の展開・収納の状態も復元します |
| ドロップでカード追加 | exe をつまみや帯にドロップすると、ダッシュボードの追加画面が入力済みの状態で開きます |
| 更新のお知らせ | GitHub に新しい版があれば知らせ、ワンクリックで更新します |

## 必要なもの

| 項目 | 内容 |
| --- | --- |
| OS | Windows 11（Windows 10 でも動作する見込み） |
| Python | 3.9 以降。インストール時に「Add python.exe to PATH」をオンにしておく |
| ブラウザ | Microsoft Edge（標準でインストール済み） |

Python が使えるかどうかは、PowerShell で次のコマンドを実行すると確認できます。パスが表示されれば準備完了です。

```powershell
Get-Command pythonw
```

## セットアップ

1. zip を好きな場所に展開します（例：`C:\Tools\DashboardBarPy`）。
   展開後にフォルダを移動すると、ショートカットや自動起動が動かなくなるので注意してください。
2. `settings.json` を開き、`Url` を実際のダッシュボードの URL に合わせます（あとから設定画面でも変えられます）。
3. 動作を確認するため、フォルダで PowerShell を開いて次のコマンドを実行します。

```powershell
pythonw dashboard_bar.py
```

画面の左端にダッシュボードが、タスクトレイにアイコンが表示されれば成功です。

### v1 から更新する場合

- `dashboard_bar.py` と `README.md` を上書きします。
- `settings.json` は今のものをそのまま使えます。新しい項目は自動で初期値が使われます。

### ダッシュボード側（index.html）

ドロップでカードを追加する機能を使うには、同梱の `index.html` で `dashboard/index.html` を上書きして push してください。

## ショートカットの作成

### 方法 1：コマンドで作る（おすすめ）

1. エクスプローラーで `DashboardBarPy` フォルダを開きます。
2. アドレスバーに `powershell` と入力して Enter を押します。そのフォルダで PowerShell が開きます。
3. 次の 1 行を貼り付けて実行します。

```powershell
$py=(Get-Command pythonw).Source; $s=(New-Object -ComObject WScript.Shell).CreateShortcut("$([Environment]::GetFolderPath('Desktop'))\DashboardBar.lnk"); $s.TargetPath=$py; $s.Arguments="`"$PWD\dashboard_bar.py`""; $s.WorkingDirectory="$PWD"; $s.Save()
```

デスクトップに「DashboardBar」ができます。ダブルクリックすると起動します。
スクリプトファイルではなくコマンドを直接実行するので、SAC にブロックされません。

### 方法 2：手作業で作る

1. デスクトップで右クリックし、「新規作成」→「ショートカット」を選びます。
2. 「項目の場所」に次のように入力します。パスは展開したフォルダに合わせてください。

```
pythonw.exe "C:\Tools\DashboardBarPy\dashboard_bar.py"
```

3. 名前を「DashboardBar」にして完了します。
4. 作成したショートカットを右クリックし、「プロパティ」を開きます。「作業フォルダー」に展開したフォルダのパスを入れて OK を押します。

### アイコンを変える（任意）

ショートカットを右クリックし、「プロパティ」→「アイコンの変更」で、フォルダ内の `dashboard_bar.ico` を選ぶとトレイと同じアイコンになります（一度起動すると作成されます）。

### ログイン時に自動で起動する

設定画面の「Windows の起動時に自動で起動する」をオンにします。
ショートカットをスタートアップフォルダに置く必要はありません。

## 使い方

### 帯とつまみ

| 操作 | 動作 |
| --- | --- |
| つまみをクリック | 展開と収納を切り替えます |
| つまみを上下にドラッグ | つまみの位置を変えます。位置は自動で保存されます |
| 帯を左右にドラッグ | 幅を変えます。変えた幅は自動で保存されます |
| 収納中に帯へマウスを乗せる | 一時的に表示します（覗き見）。つまみに乗せただけでは表示しません |
| 覗き見中につまみをクリック | その場で展開（固定）に切り替えます |
| `Ctrl + Alt + D` | 展開と収納を切り替えます |
| つまみ・帯を右クリック | メニューを表示します |
| exe をつまみ・帯にドロップ | ダッシュボードの「リンクを追加」が、タイトルと exe のパスが入った状態で開きます |

### タスクトレイ

| 操作 | 動作 |
| --- | --- |
| アイコンをクリック | 展開と収納を切り替えます |
| アイコンを右クリック | メニュー（展開／収納・再読み込み・設定…・更新を確認・終了）を表示します |

### 3 つの状態

| 状態 | 見た目 | 他のウィンドウ |
| --- | --- | --- |
| 展開 | ダッシュボードを表示 | ダッシュボードと重ならない範囲に表示 |
| 収納 | 細い帯とつまみだけ表示 | ほぼ全画面を使える |
| 覗き見 | ダッシュボードを上に重ねて表示 | 収納と同じ（マウスが離れると自動で収納） |

### 終了するには

トレイのアイコン、またはつまみ・帯を右クリックして「終了」を選びます。
確保していた画面の端の領域は、終了と同時に解放されます。

## 設定画面

トレイのメニュー、またはつまみ・帯の右クリックメニューから「設定…」を選びます。
変更はその場で反映され、自動で保存されます。

| 区分 | 項目 | 内容 |
| --- | --- | --- |
| 表示 | モニター | 表示するモニターを選びます |
| 表示 | 表示位置 | 左端・右端を選びます |
| 表示 | 展開時の幅 | 幅を数値で指定します |
| 表示 | つまみの不透明度 | つまみの透け具合を変えます |
| 表示 | ダッシュボードのURL | 表示するページです。「閉じる」を押したときに反映されます |
| 動作 | 覗き見表示 | 収納中に帯へマウスを乗せたとき、一時的に表示するかどうかです |
| 動作 | 全画面アプリの使用中は隠す | 全画面のアプリを使っている間、帯ごと隠すかどうかです |
| 動作 | 自動で開き直す | ダッシュボードのウィンドウが閉じたとき、開き直すかどうかです |
| 起動と更新 | 自動起動 | Windows の起動時に自動で起動するかどうかです |
| 起動と更新 | 状態の復元 | 前回終了したときの展開・収納の状態で起動するかどうかです |
| 起動と更新 | 更新の確認 | 起動時に新しい版がないか確認するかどうかです。「今すぐ確認」でその場で確認できます |

## 更新のしくみ

DashboardBar は、GitHub の次の場所に置いた `dashboard_bar.py` と、手元の版（ファイル先頭の `VERSION`）を比べます。

```
ymatsuda-cmyk/tools リポジトリの dashboardbar/dashboard_bar.py
```

新しい版があると Windows の通知でお知らせします。通知をクリックするか、メニューの「更新を確認」から更新すると、ファイルを置き換えて自動で再起動します。
置き換える前のファイルは `dashboard_bar.py.bak` として残ります。

新しい版を配るときは、`VERSION` の数字を上げてからリポジトリに push してください。
ほかの PC にも同じ版が行き渡ります。

## 設定ファイル（settings.json）

ふだんは設定画面で足ります。設定画面にない項目を変えたいときだけ、直接編集してください（編集後は再起動が必要です）。

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| `Url` | ダッシュボードの URL | 表示するページです。`?sidebar=1` は自動で付きます |
| `Browser` | `""` | 空の場合は Edge を自動で探します。別のブラウザを使うときは exe のフルパスを指定します |
| `Monitor` | `""` | 表示するモニターです。空の場合はメインモニターです |
| `Side` | `"left"` | `left`（左端）または `right`（右端）です |
| `Width` | `380` | 展開時の幅です |
| `MinWidth` / `MaxWidth` | `240` / `800` | 幅の下限と上限です |
| `StripWidth` | `6` | 帯の幅です |
| `TabWidth` / `TabHeight` | `20` / `68` | つまみの幅と高さです |
| `TabPosition` | `0.5` | つまみの縦位置です。`0` で上端、`1` で下端になります |
| `TabOpacity` | `0.55` | つまみの不透明度です |
| `StripColor` / `TabColor` / `ArrowColor` | グレー系 | 帯、つまみ、矢印の色です |
| `AnimationMs` | `260` | スライドにかかる時間（ミリ秒）です。`0` にするとアニメーションしません |
| `HoverPeek` | `true` | 覗き見表示をするかどうかです |
| `HideOnFullscreen` | `true` | 全画面アプリの使用中は隠すかどうかです |
| `AutoRecover` | `true` | ダッシュボードが閉じたら開き直すかどうかです |
| `RestoreState` | `true` | 前回の展開・収納の状態を復元するかどうかです |
| `StartCollapsed` | `false` | `RestoreState` がオフのときに、収納した状態で起動するかどうかです |
| `CheckUpdateOnStart` | `true` | 起動時に更新を確認するかどうかです |
| `UpdateUrl` | GitHub の raw URL | 更新を確認する場所です |
| `HideTitleBar` / `TitleBarHeight` | `true` / `32` | Edge のタイトルバーを隠すかどうかと、その高さです |

幅の単位はすべて DIP（表示倍率 100% のときのピクセル）です。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 起動しない、または何も表示されない | `dashboard_bar.log` の内容を確認します |
| 起動しても何も起きない | すでに起動しています。トレイのアイコンを確認してください |
| 「pythonw が見つからない」と表示される | Python の PATH が通っていません。Python を入れ直して「Add python.exe to PATH」をオンにします |
| 「Edge が見つかりません」と表示される | `settings.json` の `Browser` に `msedge.exe` のフルパスを指定します |
| タイトルバーが少し見える／ページの上端が欠ける | `TitleBarHeight` の値を増やす／減らします |
| ダッシュボードがずれる | 1 秒ほどで自動的に元の位置に戻ります。戻らない場合は `dashboard_bar.log` を確認します |
| 全画面でないのに隠れてしまう | 設定画面で「全画面アプリの使用中は隠す」をオフにし、どのアプリで起きたかを確認します |
| exe をドロップしても何も起きない | `index.html` の更新が GitHub Pages に反映されているか確認します。exe 以外のファイルには、いまは対応していません |
| 「更新を確認できませんでした」と表示される | GitHub の `dashboardbar/dashboard_bar.py` にファイルが置かれているか確認します |
| 端に空白が残ったまま戻らない | 強制終了などで領域の確保が残っています。一度起動してから「終了」を選ぶと解放されます。それでも残る場合はエクスプローラーを再起動します |

### 制限事項

- メインモニター以外や右端に置いた場合、隣にモニターがあると、スライド中にそちらへはみ出して見えることがあります。
- つまみは確保した領域の外側に飛び出すため、隣のウィンドウの端を少しだけ覆います。
- 展開中は、Edge のウィンドウがタスクバーに表示されます。収納すると消えます。
- 再読み込みとドロップでの追加は、ダッシュボードのウィンドウを開き直す方式です。1〜2 秒ほどかかります。
- ドロップで追加できるのは exe だけです。ブラウザからの URL のドロップにも対応していません。
- ダッシュボードは、普段使っている Edge のプロファイルで開きます。localStorage やログイン状態は Edge と共有されます。
