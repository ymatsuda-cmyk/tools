# DashboardBar（Python版）

ダッシュボードを Windows の画面左端にサイドバーとして常時表示するツールです。
左端の領域を予約するため、他のウィンドウを最大化しても右側にだけ表示され、ダッシュボードと重なりません。

- Edge のアプリモードでダッシュボードを表示します
- python.exe と Edge だけで動くため、スマートアプリコントロール（SAC）をオンにしたまま使えます
- 標準ライブラリだけで動くので、追加のインストールは不要です

---

## 必要なもの

| 項目 | 内容 |
| --- | --- |
| OS | Windows 11（Windows 10 でも動作する見込み） |
| Python | 3.9 以降。インストール時に「Add python.exe to PATH」をオンにしておく |
| ブラウザ | Microsoft Edge（標準でインストール済み） |

Python が使えるかどうかは、PowerShell で次のコマンドを実行すると確認できます。パスが表示されれば準備完了です。

```powershell
Get-Command pythonw
```

## ファイル構成

DashboardBarPy/

├─ settings.json       設定ファイル

└─ dashboard_bar.log   ログ（初回起動時に自動で作成）

## セットアップ

1. zip を好きな場所に展開します（例：`C:\Tools\DashboardBarPy`）。
   展開後にフォルダを移動すると、ショートカットが動かなくなるので注意してください。
2. `settings.json` を開き、`Url` を実際のダッシュボードの URL に合わせます。
3. 動作を確認するため、フォルダで PowerShell を開いて次のコマンドを実行します。

```powershell
pythonw dashboard_bar.py
```

画面左端にダッシュボードが表示されれば成功です。

## ショートカットの作成

### 方法 1：コマンドで作る（おすすめ）

1. エクスプローラーで `DashboardBarPy` フォルダを開きます。
2. アドレスバーに `powershell` と入力して Enter を押します。そのフォルダで PowerShell が開きます。
3. 次の 1 行を貼り付けて実行します。

```powershell
$py=(Get-Command pythonw).Source; $s=(New-Object -ComObject WScript.Shell).CreateShortcut("$([Environment]::GetFolderPath('Desktop'))\DashboardBar.lnk"); $s.TargetPath=$py; $s.Arguments="`"$PWD\dashboard_bar.py`""; $s.WorkingDirectory="$PWD"; $s.Save()
```

デスクトップに「DashboardBar」ができます。ダブルクリックすると起動します。

スクリプトファイルではなくコマンドを直接実行するので、SAC にブロックされません。

### 方法 2：手作業で作る

1. デスクトップで右クリックし、「新規作成」→「ショートカット」を選びます。
2. 「項目の場所」に次のように入力します。パスは展開したフォルダに合わせてください。

```
pythonw.exe "C:\Tools\DashboardBarPy\dashboard_bar.py"
```

3. 名前を「DashboardBar」にして完了します。
4. 作成したショートカットを右クリックし、「プロパティ」を開きます。「作業フォルダー」に展開したフォルダのパスを入れて OK を押します。

### ログイン時に自動で起動する

- **方法 1 の場合**：コマンドの `'Desktop'` を `'Startup'` に変えて、もう一度実行します。
- **方法 2 の場合**：`Win + R` を押して `shell:startup` と入力し、開いたフォルダにショートカットをコピーします。

### アイコンを変える（任意）

ショートカットを右クリックし、「プロパティ」→「アイコンの変更」で好きなアイコンを選べます。
たとえば次のファイルを指定すると、Edge のアイコンになります。

```
C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
```

## 使い方

ダッシュボードの右端にある細い帯と、帯から右に飛び出した半透明の「つまみ」（角の丸い台形）で操作します。
つまみはマウスを乗せると不透明になります。

| 操作 | 動作 |
| --- | --- |
| つまみをクリック | 展開と収納を切り替えます |
| つまみを上下にドラッグ | つまみの位置を変えます。位置は自動で保存されます |
| 帯を左右にドラッグ | 幅を変えます。変えた幅は自動で保存されます |
| 収納中に帯へマウスを乗せる | 一時的に表示します（覗き見）。つまみに乗せただけでは表示しません |
| 覗き見中につまみをクリック | その場で展開（固定）に切り替えます |
| `Ctrl + Alt + D` | 展開と収納を切り替えます |
| つまみ・帯を右クリック | メニュー（幅を初期値に戻す／終了）を表示します |

### 3 つの状態

| 状態 | 見た目 | 他のウィンドウ |
| --- | --- | --- |
| 展開 | ダッシュボードを表示 | ダッシュボードの右側にだけ表示 |
| 収納 | 細い帯だけ表示 | ほぼ全画面を使える |
| 覗き見 | ダッシュボードを上に重ねて表示 | 収納と同じ（マウスが離れると自動で収納） |

### 終了するには

帯を右クリックして「終了」を選びます。
予約していた左端の領域は、終了と同時に解放されます。

## 設定（settings.json）

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| `Url` | ダッシュボードの URL | 表示するページです。`?sidebar=1` は自動で付きます |
| `Browser` | `""` | 空の場合は Edge を自動で探します。別のブラウザを使うときは exe のフルパスを指定します |
| `Width` | `380` | 展開時の幅です。帯をドラッグすると自動で書き換わります |
| `MinWidth` / `MaxWidth` | `240` / `800` | ドラッグで変えられる幅の下限と上限です |
| `StripWidth` | `6` | 帯の幅です |
| `TabWidth` / `TabHeight` | `20` / `68` | つまみの幅と高さです |
| `TabPosition` | `0.5` | つまみの縦位置です。`0` で上端、`0.5` で中央、`1` で下端になります。つまみを上下にドラッグすると自動で書き換わります |
| `TabOpacity` | `0.55` | つまみの不透明度です（`1.0` で不透明）。マウスを乗せると不透明になります |
| `StripColor` / `TabColor` / `ArrowColor` | グレー系 | 帯、つまみ、矢印の色です |
| `AnimationMs` | `260` | スライドにかかる時間（ミリ秒）です。`0` にするとアニメーションしません |
| `StartCollapsed` | `false` | `true` にすると収納した状態で起動します |
| `HoverPeek` | `true` | 収納中に帯へマウスを乗せたとき、覗き見表示するかどうかです（つまみは対象外） |
| `HideTitleBar` | `true` | Edge のタイトルバーを画面の外に追い出して隠します |
| `TitleBarHeight` | `32` | 隠すタイトルバーの高さです |

幅の単位はすべて DIP（表示倍率 100% のときのピクセル）です。

設定を変えたときは、一度終了してから起動し直してください。
なお、幅をドラッグで変えると `settings.json` が上書きされます。

## ダッシュボード側の対応（index.html）

DashboardBar は、ダッシュボードの URL に `?sidebar=1` を付けて開きます。
`dashboard/index.html` は、このパラメータがあるときだけ縦スクロールバーを非表示にします（スクロール自体はできます）。
通常のブラウザで開いたときは、これまでどおりスクロールバーが表示されます。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| タイトルバーが少し見える | `TitleBarHeight` の値を増やします |
| ページの上端が欠ける | `TitleBarHeight` の値を減らします |
| 縦スクロールバーが消えない | `index.html` の更新が GitHub Pages に反映されているか確認し、ダッシュボードで `Ctrl + F5` を押して再読み込みします |
| 起動しない、または何も表示されない | `dashboard_bar.log` の内容を確認します |
| 「pythonw が見つからない」と表示される | Python の PATH が通っていません。Python を入れ直して「Add python.exe to PATH」をオンにします |
| 「Edge が見つかりません」と表示される | `settings.json` の `Browser` に `msedge.exe` のフルパスを指定します |
| つまみがじゃまな位置にある | つまみを上下にドラッグして移動します |
| ダッシュボードが右にずれる、タイトルバーが見える | 1 秒ほどで自動的に元の位置に戻ります。戻らない場合は `dashboard_bar.log` を確認します |
| 帯が 2 本ある | 二重に起動しています。両方を終了してから、1 つだけ起動し直します |
| 左端に空白が残ったまま戻らない | 強制終了などで領域の予約が残っています。一度起動してから「終了」を選ぶと解放されます。それでも残る場合はエクスプローラーを再起動します |

### 制限事項

- 表示されるのはメインモニターの左端だけです。
- つまみは予約した領域の外側に飛び出すため、右隣のウィンドウの左端を少しだけ覆います。
- メインモニターの左側や上側に別のモニターがある場合は、スライド中やタイトルバーの部分がそちらにはみ出して見えることがあります。
- 展開中は、Edge のウィンドウがタスクバーに表示されます。収納すると消えます。
- ダッシュボードは、普段使っている Edge のプロファイルで開きます。localStorage やログイン状態は Edge と共有されます。
